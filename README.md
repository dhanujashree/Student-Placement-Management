Student Placement Management System

A compact college mini-project built with HTML5, CSS3, Vanilla JavaScript, PHP 8+ and MySQL. It is designed to run on XAMPP (Apache + MySQL + phpMyAdmin)without frontend or backend frameworks.

Features

Student
- Registration and secure login
- Personal, academic and professional profile
- Profile completion indicator
- PDF resume upload (maximum 2 MB)
- Placement-drive search and filtering
- Automatic eligibility checking for CGPA, 10th, 12th, department and year
- Online applications with duplicate-application prevention
- Application status timeline
- Interview schedule
- Placement results
- Notifications

Admin / Placement Cell
- Dashboard statistics and simple CSS/JavaScript charts
- Student search, filters, profile viewing, editing, resume viewing and deletion
- Company CRUD
- Placement-drive CRUD
- Application search/filter and status updates
- Interview scheduling and deletion
- Result publishing
- Notifications
- Department-wise, company-wise and application-status reports
- Printable report

Technologies

- HTML5
- CSS3
- Vanilla JavaScript / Fetch API
- PHP 8+
- MySQL / PDO
- XAMPP / Apache / phpMyAdmin
